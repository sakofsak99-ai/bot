RICHFLOW CRM — Telegram-бот с ручным ведением лидов

Что умеет:
- добавлять лидов вручную;
- хранить данные в SQLite;
- показывать список лидов с пагинацией;
- открывать карточку лида;
- редактировать поля и статусы;
- фильтровать по статусу и искать по имени/Telegram/телефону;
- показывать контакты на сегодня;
- выгружать базу в CSV, который открывается в Excel/Google Sheets;
- ограничивать доступ одним Telegram ID владельца.

УСТАНОВКА НА КОМПЬЮТЕР / VPS / BOTHOST
1. Установить Python 3.11 или новее.
2. Распаковать архив.
3. Открыть терминал в папке richflow_crm.
4. Создать виртуальное окружение:
   python -m venv .venv
5. Активировать:
   Windows: .venv\\Scripts\\activate
   macOS/Linux: source .venv/bin/activate
6. Установить зависимости:
   pip install -r requirements.txt
7. В панели хостинга открой настройки переменных окружения и добавь:
   BOT_TOKEN — токен бота от @BotFather.
   OWNER_ID — твой числовой Telegram ID.
   DB_PATH — richflow_crm.sqlite3 (необязательно; это значение используется по умолчанию).
8. Сохрани переменные и перезапусти приложение.
9. Запустить локально можно так:
    python bot.py

ПЕРВЫЙ ЗАПУСК
- Напиши боту /start или /menu.
- Нажми «Добавить лида».
- Заполняй поля по очереди.
- Если поле неизвестно, отправь дефис: -
- База создаётся автоматически по пути из DB_PATH (по умолчанию richflow_crm.sqlite3).

ВАЖНО
- Бот работает, пока запущен процесс Python. Для постоянной работы нужен VPS/сервер или постоянно включённое устройство.
- Не отправляй никому токен бота. Если токен утёк, перевыпусти его через @BotFather.
- Делай резервные копии файла richflow_crm.sqlite3.
- Доступ ограничен указанным OWNER_ID; не передавай этот ID посторонним.
- Даты для поля «Следующий контакт» вводи строго ДД.ММ.ГГГГ, например 24.11.2026.
- В этой стартовой версии напоминания не отправляются автоматически: раздел «Контакты на сегодня» показывает записи, у которых дата следующего контакта совпадает с сегодняшней.


КОНФИГУРАЦИЯ
- Проект больше не читает .env и не использует python-dotenv.
- BOT_TOKEN и OWNER_ID обязательны и задаются в переменных окружения хостинга.
- DB_PATH необязателен; если не задан, используется richflow_crm.sqlite3.
- Не добавляй токен в исходный код, GitHub или публичные сообщения.
